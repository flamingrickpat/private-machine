## Topology acceptance

`tests/test_topology.py` extends `pm_workflows.dryrun` instead of adding a
second graph engine. It discovers every `workflows/**/*.workflow.md`, then for
each manifest checks:

- no blocking file or parse error,
- every edge destination is a declared phase or a terminal,
- a terminal is reachable from the first phase,
- every edge to `<stop>` is a declared success-ish outcome, not a dead end,
- every cycle has a finite per-phase bound and a non-terminal exit,
- the `local_task_question` human phase declares a non-terminal exit,
- warnings are limited to the accepted waiting-phase default cap,
- a seeded 500-run simulation is deterministic and stays within static bounds,
- the generic bus and runtime contain no workflow-name special case.

The extension rule is satisfied without a bus or runtime special case: the
managed workflows are wired only through their folder, application wiring, and
tests. `test_generic_bus_and_runtime_have_no_workflow_special_case` scans
`bus/bus.py`, `bus/envelopes.py`, `runtime/shell.py`, and
`runtime/workflow_runner.py` for every workflow name and fails on a match.

```powershell
uv run --locked python -m unittest tests.test_topology -v -b
```

Result: 9 tests passed.

## Conversation acceptance

The harness runs ten scenarios with twenty exchanges each. Fake Jesse is a
real generation call with a scenario-specific role; it sees only the public
transcript, its own role, and the scenario facts. The companion is the real
Assistant dialogue module: persona, private ontology, tool-capable session,
and committed memory. Each scenario uses its own Ghost copy that persists
across all twenty exchanges.

Scenarios: casual banter; shared-event recall and correction; insult and
reconciliation; topic change under an existing goal; urgent fictional event
with irrelevant visual detail; impossible physical request; start a real local
workflow and ask status; update and terminate an active run; resolve a
blocking managed question; and task-failure continuation.

Generation for the whole batch finishes before the evaluator is activated.
The evaluator reads saved transcripts and never rewrites a reply. It returns
`scale` (trajectory) plus per-reply immersion, voice, groundedness, and
coherence. The gate requires seven good trajectories out of ten, no hard
contract violation, and no evaluator error.

```powershell
uv run --locked python -m unittest tests.live.test_conversations -v -b
```
