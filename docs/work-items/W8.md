## Minecraft body

The body is a Python-role workflow. It receives a goal and one bounded action,
observes the world through the injected `minecraft_call` tool, executes the
action, and writes real evidence:

- `scratch/observations.md` — bounded text observations.
- `outbox/world.yaml` — structured places, objects, and one body episode.
- `screenshots/frame-NN.png` — the real screenshot pixels from the tool result.
- `outbox/report.yaml` — the typed report.

`minecraft_call` owns an HTTP connection to the configured pm-minecraft MCP
endpoint (`MINECRAFT_MCP_URL`, default `http://127.0.0.1:6767/mcp`). It returns
the structured result and extracts each image content part as base64 with its
media type. Screenshot pixels become files; they never enter a prompt or a
text memory.

The role checks `wait_for_cancel` after writing its durable evidence, which
gives the managed-run and steward contracts an explicit safe boundary.

## Consolidation extension

Consolidation now reads `outbox/world.yaml` and real image files. It proposes:

- `WorldPlaceKnoxel` for each place.
- `WorldObjectKnoxel` for each nearby block object.
- `BodyEpisodeKnoxel` for the episode, with `evidence["images"]` entries that
  each carry media type, base64, source artifact, content hash, and
  observation time.

The receipt records the image hashes, media types, and paths. A repeated
request reuses its receipt instead of duplicating memory. A changed image
produces a new receipt. Text content is the only field eligible for an
embedding or a dialogue prompt. Task folders are never deleted, so a failed
consolidation preserves evidence.
