# Develop and inspect a change

Use a separate character home so your comparison starts from known memory.
Choose an input and record the expected behavior. Keep the resulting trace.

1. Read the repository instructions and the [system map](../concepts/architecture.md).
2. Start a character with the [example setup](example-characters.md).
3. Capture a real exchange. Find its owning workflow in the debugger.
4. Change the owning source or prompt. Restart the character and repeat the input.
5. Compare receipts. Use the [Spamuel baseline](spamuel-baseline.md) for simulation comparisons.

See the [Kanban board](kanban.md) for work in progress and
[evidence and quality](../concepts/evidence.md) for interpreting results.
