# Deeper qualia and ontology

## The idea

A17 adds qualia channels and a working private ontology.
Beta can deepen both.

The channel manifold projects the mental state into inner-experience channels.
The private ontology gives the companion stable words for those channels.
Together they let the companion describe an inner life in consistent terms.

## Rough scope

- Extend the channel set from the old `qualia_channels.md` design.
- Add velocity, acceleration, and channel interaction.
- Add the poison-bin check that rejects a channel value without a real driver.
- Let the ontology term set grow from accepted experience.
- Let a term bind to features and state with a fit score.
- Add the interlocus variable: inward focus versus outward focus.
- Add reportable qualia only through the causal gate.

## Open questions

- How many channels stay useful instead of becoming noise?
- How do we test that a channel describes real state?
- How does a persona-appraised reading of a channel stay grounded?
- How does this interact with public speech (A09R)?
- Does the companion ever talk about qualia directly, or only use them?
