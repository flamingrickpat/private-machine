# A19: Reflect, test hypotheses, and revise behavior

## Summary

This item makes reflection produce tested changes to beliefs and behavior.
It is not implemented by this plan.

Parent: [ordered alpha plan](../index.md).
Dependencies: A07, A16–A18.
Design: [self-model and reflection](../reflection.md#self-model-and-reflection).

### Deliver

1. Develop monitor–assess–guide workflows inside the second conscious loop.
2. Form explicit behavioral hypotheses, conduct permitted interventions, and compare later outcomes.
3. Commit belief, goal, attention, or configuration changes with durable explanations and reversal history.
4. Let the companion change workflow configuration and cognitive resources as one reflection outcome.

D07 confirms changes to goals, beliefs, attention, and workflow configuration with durable history.
Reflection is a practical control mechanism.
It does not require a third conscious personality or another state owner.
Source modification is not the proposed default.

A reflection can change cognitive resources in this item:

- Reprioritize, defer, refuse, or replace a goal through the ordinary goal path.
- Change a codelet activation threshold or cooldown in the codelet catalogue.
- Change a routing question or a workflow configuration.
- Change an attention policy value.

Each change is versioned and reversible.
Each change records the observation, the explanation, the expected effect, and the follow-up evidence.
The companion can reverse its own change.
Source-code modification stays a separate opt-in preference.
Read [the decision register](../decision-register.md) for that preference.

### Start from

A17 private workflows, A18 self-model evidence, and A16 regulation/identity codelets.
Inspect the old architecture-reflection and thought-graph concepts.
Use current versioned workflow resources and Ghost proposal acceptance.

A mismatch can concern repeated mining failures, missed user preferences, inconsistent capability claims, or unproductive rumination.
A reflection records the observation, explanation, expected effect, intervention, and follow-up evidence.
A failed intervention updates the hypothesis rather than declaring success.

### Verify

Introduce a repeatable mistake with a known feasible correction.
Verify a concrete strategy change and improved next relevant behavior.
Reverse the change and retain the full causal history.
Test a misleading diagnosis and observe correction.

An introspective discovery can alter emotional state through appraisal.
Regulation can support a sad persona without forcing immediate reassurance.
Useful reflection must remain distinguishable from repeated self-description.

### Manual test

Complete M6.
Discuss an actual failure, inspect the proposed improvement, and observe its effect during play or conversation.

### Handoff

Supply reflection contracts, permitted controls, experiment evidence, reversal commands, and limitations on self-assessment.
