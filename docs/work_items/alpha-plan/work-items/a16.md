# A16: Deliver a grounded codelet repertoire

## Summary

This item delivers grounded codelet families whose interactions affect behavior.
It is not implemented by this plan.

Parent: [ordered alpha plan](../index.md).
Dependencies: A15.
Design: [codelet lessons](../previous-attempts.md#codelets-and-internal-thought).

### Deliver

1. Rewrite an initial repertoire of roughly 24–40 useful codelets across the old catalogue's ten families.
2. Add explicit pathways and persona-dependent activation without narrator or invented-history framing.
3. Demonstrate causal family interactions through real scenarios.

The ten families cover appraisal, memory, imagination, valuation, identity monitoring, coping, needs, attention, action tendencies, and narratives.
The count is a delivery range, rather than a behavioral acceptance metric.
Add further codelets when a concrete missing behavior justifies them.

### Start from

`C:\source\pm\pm_next\pm_core\subsystems\codelet\codelet_definitions.py`.
Inspect `pathways_detailed.py` as design material.
Rewrite prompts around current state, attributed memories, and capabilities.

Include disappointment/repair, curiosity/exploration, shared achievement, concern/recovery, self-doubt, and deliberate focus.
Imagination produces possibilities with explicit attribution.
Narrative integration cannot invent executed past events.

### Verify

Demonstrate several multi-family pathways with real generation.
A retrieved failure can influence simulation and then a changed method.
A shared success can influence affect, memory, and a later cooperative goal.

Verify mixed feelings, competing motives, and negative affect without a mandatory cheerful conclusion.
Codelets that never activate or never affect accepted behavior remain unproven.
Measure the selected subset and inference consumption per scenario.

### Manual test

Replay a meaningful shared event with two trait profiles.
Inspect activated families and compare later choices.
Evaluate whether the difference feels causally consistent.

### Handoff

Supply the repertoire catalogue, activation evidence, pathway traces, persona configuration, and documented inactive definitions.
