## Verify

Use real inference and embeddings with the complete Spamuel seed in an isolated checkpoint.
Inspect stored results and later application context.
Run normal consolidation and recall before the separate failure cases.

| Case | Required evidence |
| --- | --- |
| Initial history | Seed sources enter the initial input segment without fabricated prior completion |
| Mixed channels | Interleaved dialogue and private thought retain separate clusters and overlapping time ranges |
| Complete window | Summaries, extracted knowledge, graph records, and cursor survive one checkpoint reopen |
| Retrieval | A later choice uses a compressed memory while required facts and source attribution remain available |
| Graph search | A real query reaches supported records through committed edges after index rebuild |
| Need and agency | New experience lowers integrity, committed work raises it, and a self-origin decision starts consolidation |
| Foreground work | Conversation interrupts consolidation, receives its reply, and later consolidation resumes |
| Compatibility | Existing canon and checkpoints preserve canonical mental state after duplicate-holder removal |

Exercise recovery separately:

| Case | Required evidence |
| --- | --- |
| Interrupted window | Before commit, cancellation or process death leaves the cursor and accepted window output unchanged |
| Commit crash | Restart sees either the old checkpoint or the complete new checkpoint |
| Concurrent input | A lower reserved record ID that commits later still enters a future window |
| Source revision | A stale source or ancestor update rejects the complete window without lost newer state |

Measure context reduction separately from recall quality.
Preserve failed runs and missing coverage.
Run foundation suites, relevant real gates, and complete HTML regeneration.
