# A19G: Run the inner loop on the shared cycle

## Summary

Move the private inner loop onto the typed cycle from [A19F](a19f.md).
The inner loop reads the self shard and writes its own content through the same CSM, codelet, structure, and attention mechanics.
It later takes over the functions of a metacognitive layer.
This item is planned, not delivered. Its detailed plan follows A19F.

Parent: [alpha plan](../index.md).
Dependencies: [A19F](a19f.md).
Decisions: D23 and D28 in the [decision register](../decision-register.md).

## Deliver

1. Give the inner loop typed state fields in place of `CycleState.internal_data`.
2. Run inner cycles on the shared CSM and the shared codelet registry, with a smaller budget.
3. Publish inner thoughts into the self shard tail.
4. Keep deliberate focus bounded, as A19F defines.
5. Plan the metacognitive functions: expectation violations, corrective goals, and self-management.

## Known defects to fix

- Main measures affect decay from the newest cycle state timestamp. Inner cycles write a new timestamp with an unchanged vector, so the time before each inner cycle never decays.
- Main reads the newest turn summary from any slot. It can read an inner summary as its own state.

A19F replaces both paths for main cognition. A19G must make sure that the inner loop does not bring them back.
