# A05: Wire LLM classification in PM and retain optional Laya

## Summary

This item wires A04's LLM classification through PM and retains Laya as an optional experiment.
Existing workflows keep their current models and execution paths.
The delivered [PM connection provider](../../../subsystems/workflow-inputs/pm-connections.md) and [demonstration](../../../workflows/classification-demo.md) establish the normal LLM path.
[M1 evidence](../../verification/a05-pm-classification.md) records real artifacts, isolated recovery, compaction, and compatibility.
Optional PM Laya wiring remains deferred; no new Laya use is adopted.

Parent: [ordered alpha plan](../index.md).
Dependencies: A01–A04.
Design: [candidate cognitive uses](../decisions.md#candidate-cognitive-uses) and [live cycle](../cognition.md#the-live-cycle).
Policy: [model selection and reliability](../model-policy.md).

### Deliver

1. Wire the normal LLM connection and runtime injection for classification through PM.
2. Provide a new demonstration workflow that selects and classifies real artifacts without Laya.
3. Retain the optional decision client and record whether a simple Laya candidate merits further use.

D01 confirms capability availability without forced adoption.
No existing cognitive stage must switch to Laya for this item to pass.
The normal LLM is the primary path for classification and interpretive decisions.

### Start from

`pm/llm/config.py`, `model_activation.py`, `main.py`, and `runtime/workflow_runner.py`.
Reuse existing chat configuration and supply A04's LLM demo through PM.
Add optional decision configuration and lazy activation only when a qualifying simple use warrants that integration.
If that integration requires expensive effort, retain the standalone client and defer PM Laya wiring.
Deferred Laya wiring does not block this item or later items.

A workflow explicitly opts into the decision node.
Unused decision configuration must not launch a service or make a request.
Existing workflows run when no Laya endpoint is configured.

Candidate comparisons use captured inputs and a separate experiment path.
They must not mutate Ghost, dispatch actions, or replace active stage outputs.
Laya answers do not supply generated explanations or arbitrary evidence identifiers.

### Verify

Run existing workflows with Laya absent and verify the same model selection and execution path.
Run the new PM demo with the configured normal LLM.
Inspect selection, classification, INVALID fallback, and service activation receipts.
Verify direct Python classification and agentic long-file inspection through their actual runtime paths.
Repair LLM connection or context failures before delivery.

Before enabling any Laya candidate, write live-endpoint unit tests with realistic synthetic data and independent expected results.
Include captured application inputs when available and untouched cases that prevent fitting only known examples.
Compare that simple use with the existing LLM on identical inputs.
Report wrong answers, critical misroutes, uncertainty, fallback rate, latency, and lost evidence information.
Simple assertions need no separate human-label approval.
Keep human review for ambiguous interpretation and persona immersion.
If Laya fails or requires extensive work, reject the candidate and keep the LLM.
Do not turn missing old corpus reviews into a blocker for normal LLM delivery.

A measured recommendation is not an automatic migration.
Record any future adoption as an explicit, separately scoped workflow change.
Choose the model according to the task rather than a target percentage of Laya usage.

### Manual test

Complete M1 through the new PM demo.
Run a current conversation or coding workflow with the decision service stopped.
Verify that it retains its current behavior and does not attempt a Laya request.

### Handoff

Supply LLM connection wiring, the PM demo, baseline compatibility evidence, candidate disposition, and tested package locks.
State whether optional Laya wiring exists or remains deferred, and identify any exact use that passed live tests.
