### Deliver

1. Give Story and Assistant paths the same identity, affect, goals, memory, and selected workspace context.
2. Replace stale capability descriptions and global physical-verb bans with domain-aware evidence rules.
3. Handle stale reply work, protocol failures, and deliberate disclosure choices explicitly.

D02 confirms private thoughts remain private unless the companion chooses a public action.
The later inner shard supplies the selected mental landscape.
Public output should not expose a narrator or raw thought transcript by default.

### Start from

`workflows/dialogue_story/prompts.yaml`, `context.py`, `ontology.yaml`, and `situation.yaml`.
Inspect Assistant prompts and `workflows.dialogue_story.host.StoryDialogue` publication.
Read [A08 verification](../../verification/a08-experienced-memory.md) for continuity receipts and unsupported historical recall.
Its failed-method reply invents a recap failure despite retrievable original evidence for the wrong-file follow-up.
Preserve those failed replies when evaluating public grounding.
Use current capability configuration and task evidence as context.
Apply the [private ontology contract](../ontology.md) to each generating agent and final claim validation.

Minecraft perception and action are distinct from a physical human body.
Imagined events retain attribution.
The companion can discuss its nature without repeating an automatic disclaimer every turn.

### Verify

Run real conversations across practical work, affection, frustration, uncertainty, and task interruption.
Verify that both dialogue paths express the same persistent state and identity.
Inspect capability answers with Minecraft disconnected and connected.

A rejected output or stale generation must have an observable recovery path.
Repeat [A01 C01](../baseline/receipts.md#diagnosed-conversation-failure) through the real console.
Retain that control-worker case as a managed-run/public-reply regression.
Also run a real agent-backed note task and inspect the requested file's exact bytes.
The control worker's completed status cannot establish arbitrary instruction execution or a successfully written note.
A successfully verified task must produce a useful public reply tied to its receipt.
Failed or stale publication must expose its recovery outcome.
A terminal task must not silently leave its user exchange pending.
Repeat C02 and compare restart claims with retrieved original records and checkpoint evidence.
Retained records cannot support a claim that those records disappeared during restart.
A deliberate choice to keep a thought private is distinct from a runtime failure.
An intentional lie requires a prior accepted deception intent and retained factual context.
Unsupported prose cannot be relabeled as conscious deception after generation.
Test unimplemented senses and emotion terms against the private ontology.
Verify that public utterances do not automatically become true autobiographical memories.
The evaluator must not repeatedly rewrite valid replies until a score passes.
