# A09R: Agentic public voice and the private ontology

## Summary

This item replaces the fixed public-review policy with an agentic, persona-driven voice.
It also implements the private ontology as state.
The strict statement-by-statement claim gate was too explicit and too slow.
The later weighted hallucination policy kept the same hardcoded shape.
This item removes that shape.
It does not re-open the A09 receipts.
It supersedes the A09 review mechanism.

Parent: [ordered alpha plan](../index.md).
Dependencies: A08, A15.
Supersedes: [A09](a09.md).
Design: [private ontology](../ontology.md), [second conscious loop](../private-loop.md), and [confirmed D02/D10](../decision-register.md#confirmed-direction).
Subsystem: [story speech](../../../subsystems/story-speech.md).
Current delivery: [OpenRouter repairs, evidence, and session handoff](../../verification/a09r-openrouter-delivery.md).
Human M2 review and conversation-latency acceptance remain pending.

### Deliver

1. Implement the private ontology as durable state.
2. Make public speech generation and review agentic and persona-driven.
3. Keep only a false task result as a hard block.
4. Record the reason for each accepted reply.

### The private ontology is state, not a gate

Read [the private ontology design](../ontology.md).
Use the existing record and provenance models.
Do not add another ontology database.

Add an ontology term record and a binding record.
A term has a name, a kind, a definition, a usage rule, and a stability value.
A binding links a term to the features or state that support its current use.
A term can be a quale word, a mood word, a relationship label, or a mental move.

The ontology is advisory.
The companion draws on it to describe its inner life in consistent words.
The ontology does not reject a reply sentence by sentence.
An unsupported label does not block speech.
It stays visible as an unsupported label for review.

The old `pm_next` records `OntologyTermKnoxel` and `OntologyBindingKnoxel` are design material.
Inspect them before writing the new record.
Keep the current record schema style.

### The voice is agentic

The [story-speech](../../../subsystems/story-speech.md) message layout is the starting point.
Keep the three-message shape: system, derived-context user turn, and verbatim assistant turn.

Replace the fixed review with an agentic step.
The companion chooses its presentation before generation.
The choices are candid speech, withholding, and deliberate deception.
A deception choice carries a prior intent, the known facts, and the purpose.
The runtime never relabels a hallucination as a lie after generation.

The review is one model step with a persona-aware prompt.
It judges the reply against the accepted state, the abilities, the ontology, and the task results.
It returns a short judgment and the reason.
It does not assign per-kind weights from a policy file.
It does not regenerate until a score passes.

Keep `false_task_result` as the only hard block.
A false task result can change the user's actions on a real object.
A persona-driven prompt or a persona we might trust with lies and metaphors must not
become a false task result.

### Keep the useful parts of the old path

The hallucination review found real invented abilities and invented events.
Keep those findings as review output, not as a numeric gate.
The assistant path keeps its one review and its tool receipts.
A second tool run could change the world, so only a false task result rejects an
assistant reply.

The blocking path still publishes an explicit recovery text.
Keep the recovery distinct from a normal reply.
Keep the receipt beside it.

### Verify

Run real conversations across practical work, affection, frustration, uncertainty, and interruption.
Both dialogue paths must express the same persistent state and identity.

Verify these cases:

- An invented ability is reported by the review and does not become an accepted belief.
- An invented event is reported by the review and does not become an accepted memory.
- A false task result is blocked and produces the explicit recovery text.
- A prior deception intent produces a deliberate false statement with retained factual state.
- A metaphor, exaggeration, or teasing line is not blocked.
- An unsupported emotion label stays visible and does not create an emotion field.
- The reply latency for an ordinary turn stays suitable for conversation.

Check that the review returns one judgment and one reason.
Check that no reply is rewritten repeatedly until it passes.
Compare a rule-based baseline and the agentic review on the same captured replies.

Repeat the A09 note case and the C01/C02 regression cases through the real console.
Keep the old A09 receipts beside the new ones.

### Manual test

Complete M2 again with this mechanism.
Ask about a capability, a remembered goal, and a private topic.
Rate continuity and the desire to regenerate each reply.

### Handoff

Supply the ontology record schema, the binding rules, the review contract, the
deception-intent path, the recovery path, and real conversation receipts.
Record the latency and the reply count per exchange.
