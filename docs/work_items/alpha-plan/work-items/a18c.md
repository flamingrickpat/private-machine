# A18C: Deliberate attention and control of private thought

## Summary

Give the companion an actual wait action, deliberate mental work, and bounded private episodes.
Mental actions propose changes through ordinary appraisal, codelets, and attention.
They do not replace emotions or the accepted workspace directly.
The owner accepted this implementation for alpha on 17 October 2026.
The complete A18B evaluation remains unverified.

## Owner requirements

Silence can be the correct personal choice.
Repeated inference about ending inference is the defect exposed by the [A18B stall](../../verification/a18b-errors/stall.md).
Do not force a public reply to conceal that defect.

An accepted wait suspends routine cognition until outside evidence or a configurable deadline arrives.
The initial default is 30 minutes.
The timeout supplies elapsed-time evidence and another choice, not compulsory speech.
Event intake and already authorized external work remain active.

The companion can deliberately recall interests, conversations, and preferences.
It can discover an activity, propose a goal, defer a concern, or suggest a different focus.
The agent chooses and composes these operations.
No emotion-to-activity table or compulsory cooperative response belongs in this item.

Deliberate focus provides strong but bounded influence.
Appraisal, codelets, competing concerns, and urgent new evidence retain influence.
An unwanted concern can return.
The workflow cannot erase a memory or assign an emotion.

## Delivery boundaries

| Wait for stimulus | Controller, assembly, atomic wait commit, cancellation, and timeout outbox are wired |
| Restart | Accepted waits retain their sources. Recovery does not redispatch those sources as fresh input |
| Private recall | A bounded retrieval tool reads the frozen invocation snapshot and guards retrieved revisions |
| Deliberate mental-work agent | Real full-canon recall committed inspected sources and passed main appraisal. Real timeout and provider-error recovery passed |
| Focus acceptance | Fresh rejections and still-effective advice stay separate. The current cap clamps stored advice |
| Multi-step private episodes | Real full-canon steps retained one identity, waited for main appraisal, and closed at the configured step limit. Parking and restart boundaries have separate checks |
| Private goal proposals | Both private thoughts and deliberate mental work retain advice for the main goals stage |
| Harness pause outcome | A committed wait for the current exchange ends generation. Unseen scenes remain incomplete |

A working wait does not establish the other mechanisms.
Compilation does not establish runtime behavior.
Human immersion review remains separate from model-generated evaluations.
The mental-work boundary tests use a fake agent driver. Separate full-canon gates use real agent sessions and actual services.
Focused live checks passed for recall, focus influence, urgent competition, real expiry, episodes, parking, pauses, and failure recovery.
The owner reviewed the verification record and accepted the result as sufficient for alpha.
This acceptance assigns no detailed ratings for voice, recall usefulness, or immersion.

## Beta boundary

Keep stable original IDs, chronology, causal links, goal links, and episode membership.
Topic hints remain advisory and revisable.
An episode is not a permanent topic cluster.
Several later abstractions can cite the same source.

Do not implement topical clustering, fragmentation-triggered maintenance, or dreaming here.
Imagined content must retain its attribution.
An executed simulation can be an internal event without making its imagined outcome an observed fact.
