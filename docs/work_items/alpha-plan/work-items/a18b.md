# A18B: Cognitive believability evaluation

## Summary

Build a reusable repertoire that detects weak immersion, emotional discontinuity, repetition, and unsupported claims.
Run the full companion with an independent Jesse actor, then review frozen evidence through blinded model calls.
Integrate mechanism tests and real reviewer gates with native unittest.
Keep human review available for all cases and problem cases.

## Owner requirements

Use varied situations that extend beyond the earlier ten-message conversations.
Use normal thoughtful back-and-forth as the primary interaction pattern.
Preserve asynchronous speech and unsolicited messages.
Keep overlap bursts as explicit lower-priority edge cases, near 15 percent of the repertoire.
Restrict Minecraft to 25 percent of the repertoire.
Keep reviewers unaware of private architecture and backstory unless selected evidence is required for a specific claim.
Provide documented scripts, native test entry points, all-case inspection, and problem-only inspection.
The 24-hour example indicates future case volume; it is not a required run duration.

## Delivery scope

Declare 16 scenarios with four scenes each.
Cover emotional repair, mixed outcomes, corrections, privacy, initiative, teasing, long absence,
restart, overlapping topics, mental-state language, conflicting preferences, and four modest Minecraft conversations.
Use separate literary and factual audiences, each with two independent panel passes.
Partition each pass into small criterion groups with fresh context per call.
Apply the shared 30,000-token test input limit; do not silently truncate required evidence.
Retain exact requests, quotations, source origins, protocol failures, and human review status.

At least 80 percent of cases must pass at least 75 percent of criteria.
The normal cases must independently meet that 80-percent threshold.
Every case must pass at least one third.
Missing runtime or reviewer evidence prevents a suite pass.
Unsupported external results and unsupported literal mental mechanisms are critical failures.
No average can hide those failures.

## Gates and handoff

Run root unit and contract suites and the real 12-control reviewer calibration.
Run selected fresh full-canon cases and inspect the resulting packets and reports.
Do not claim all 16 behaviors passed without complete fresh evidence.
Record unavailable endpoints and runtime failures explicitly.
Rebuild and inspect the HTML manual.
Keep A19 on hold while A17/A18 hardening and cognitive evaluation evidence remain under review.
