# A10: Run one sustained Minecraft specialist session

## Summary

This item allows a Minecraft specialist to complete a meaningful task through many real tool calls.
The engineering delivery is recorded.
The [actor guide](../../../subsystems/minecraft-actor.md),
[controls](../../../subsystems/minecraft-actor-controls.md), and
[verification](../../verification/a10-minecraft-actor.md) describe the implementation and retained real evidence.

Parent: [ordered alpha plan](../index.md).
Dependencies: A04, A09.
Design: [specialist structure](../minecraft.md#specialist-skill-structure) and [body ownership](../minecraft-operations.md#body-ownership-and-session-lifetime).

### Deliver

1. Factor the survival skill into shared and specialist resources without modifying the upstream skill.
2. Extend managed runtime wiring for pm-coder, scoped MCP, child configuration, and multimodal evidence.
3. Execute one meaningful leaf through a sustained actor session with a single body mutation lease.

D12 confirms Babymode with isolated worlds.
D13 requires a finished house and mined-iron pickaxe at M3, after A13.
Remove the schema's one-action constraint.
Do not replace it with another arbitrary tool-call ceiling.

### Start from

`main._managed_workflows`, `pm/runs/supervisor.py`, and `WorkflowSpec`.
The worker needs actual `agent_model`, MCP descriptors, cancellation, and child scoping.
Inspect `workflows/minecraft_body/mcp_client.py` and the current Minecraft manifest/steps.
Expose appropriate Minecraft tools to Assistant dialogue for direct requests, including inventory questions.
A direct read does not start a managed task.
Declare a direct Assistant pathway for clear tool questions without requiring Laya for its routing.
Preserve pm-coder's automatic compaction during sustained specialist work.
Repair actual LLM connection or lost-context failures before delivering the actor.
Any direct world mutation follows the same body ownership rules.

Use pm-coder's native session and context-compaction behavior.
Use pm-minecraft's current schemas as authority.
Text-only models must not claim they interpreted screenshot contents.

### Verify

Run “Gather wood from five trees and return.”
The actor must inspect, travel, harvest, handle inventory, and verify progress.
Record its real calls, observations, and artifact handoff.

Chat remains usable during the task.
An instruction update reaches the actor between actions.
Cancellation stops future actions.
A second actor cannot obtain the same avatar's mutation lease.
An inventory question routes directly to one observation call and an evidence-backed reply.

### Manual test

Run the developer wood-task check in a real world with nontrivial travel.
Inspect inventory/position evidence and the actor journal.

### Handoff

Supply specialist resources, model/MCP configuration, body lease rules, task outcome schema, and exact live commands.
Explain which visual inputs the configured actor can actually interpret.
