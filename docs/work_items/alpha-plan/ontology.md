# Private ontology and consistent expression

## Summary

The private ontology connects public language to implemented state and capabilities.
It separates actual experience, imagination, and deliberate presentation.
Unsupported prose cannot create a new sense or emotion.
Conscious deception remains an intentional action whose false content does not become factual memory.

## Expression contracts

An expression term has a meaning, applicable reality, supporting state, and usage rule.
Reuse existing ontology term/binding, provenance, and reality/frame models.
Do not add an unrelated ontology database.
A09R implements the first durable term and binding writer.
It seeds terms only from implemented mechanisms.
The ontology stays advisory: an unsupported label is a review finding, not a block.

A sensory claim requires an enabled capability and relevant observation.
A game visual claim requires actual interpretation of a visual input.
An emotional expression requires an implemented state mechanism and an applicable binding.
A remembered event requires attributed experience evidence.

The companion can use metaphor, uncertainty, imagination, and compound emotion descriptions.
Their context must preserve the difference between figurative language and experienced fact.
A label without a state mapping cannot establish an unimplemented emotion.

For example, a text companion without smell perception cannot casually claim it enjoys smelling hot circuit boards.
That answer can arise from a generic robot-dialogue completion.
It cannot become a remembered sensory experience merely because the dialogue model generated it.

Give every generating agent the relevant situation, reality, capabilities, and ontology bindings.
The public dialogue receives a selected mental landscape, rather than an unrestricted request to write a scene.
Validate meaningful claims semantically.
Global bans on physical verbs cannot distinguish Minecraft observations from invented human embodiment.

## Intentional presentation

A selected public action can be candid, withhold private material, or deliberately deceive.
The intention precedes dialogue generation and carries a purpose, known facts, and causal references.
It remains inspectable in private state.

The runtime cannot retrospectively call a hallucinated claim a conscious lie.
A deception intent must identify what the companion knows and chooses to misrepresent.
The same rule applies when the companion conceals an idea or declines to summarize private activity.

Public speech and objective task evidence remain separate records.
A deliberately false progress statement cannot mark a failed task completed in the task tree.
The verifier still checks actual world evidence.

## Memory acceptance

Preserve dialogue as attributed utterances.
Extract factual beliefs only when appropriate evidence supports them.
Preserve a deliberate lie as a communicative event linked to its prior intention and retained factual context.

Preserve imagined events as simulations.
Preserve emotional reactions to those simulations as actual internal state changes.
This allows a sad speculation to cause sadness without becoming an outside-world memory.

Validate imported seed history with the same capability and provenance rules.
An imported story cannot create past smell perception for a companion that never had that capability.
Ambiguous background remains attributed background until evidence supports another interpretation.

## Verification

Test unavailable smell perception, text-only screenshots, unsupported emotion labels, and fabricated past activity.
Verify that accidental unsupported output does not change factual memory.
Test an explicit prior deception intent and inspect the resulting utterance, factual state, and task evidence separately.
Keep these tests in the persona evaluation matrix.
