# Source-aware self-model and reflection

## Summary

The companion can inspect implementation evidence and revise its beliefs about itself.
Reflection operates inside the second conscious loop.
It tests a concrete behavioral hypothesis and follows its consequences.
Emotional appraisal can respond to a discovery without changing the inspected facts.

Parent: [cognitive architecture](cognition.md).

## Self-model and reflection

The self-model records current capabilities, limits, implementation evidence, and unresolved beliefs.
A18 supplies tools to inspect source, documentation, model connections, and active workflow wiring.
Every implementation claim carries a revision or evidence reference.
A plan in documentation does not prove a live capability.

The companion can infer that its design supports behavior resembling an inner life.
It can also recognize that source code does not establish human consciousness.
This conclusion should follow inspected evidence.
Do not hardcode a particular verdict as a personality script.

A cheerful persona might remain curious about that uncertainty.
A dramatic persona might appraise it as a loss or threat to identity.
Both personas retain the same factual evidence.
Their emotional response evolves through ordinary appraisal and regulation.

A19 develops monitor–assess–guide work inside the second conscious loop, inspired by [MIDCA](https://ojs.aaai.org/index.php/AAAI/article/view/9886).
It detects a concrete mismatch, forms a hypothesis, chooses an experiment, and compares the result.
It then revises a belief, goal, attention rule, or permitted workflow configuration.

Reflection needs consequences beyond a paragraph about reflection.
Track the next relevant behavior and the expected effect.
Keep strategy changes versioned and reversible.
Source modification is a separate preference in the [decision register](decision-register.md).

Memory retrieval, planning, and reflection improved believability in the original [Generative Agents study](https://arxiv.org/abs/2304.03442).
That result motivates evaluation of these mechanisms here.
It does not predict perfect immersion for this system.
