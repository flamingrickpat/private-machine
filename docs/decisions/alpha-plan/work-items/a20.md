# A20: Verify the integrated alpha in sustained use

## Summary

This item verifies the integrated alpha during sustained real conversation and Minecraft use.
It is not implemented by this plan.

Parent: [ordered alpha plan](../index.md).
Dependencies: A01–A19.
Design: [M7 and evaluation contract](../cognition-verification.md#m7-sustained-alpha-trial).

### Deliver

1. Run the integrated real-endpoint acceptance matrix and resolve material failures.
2. Expose state, task, decision, codelet, shard, and reflection evidence through the existing console.
3. Publish a reproducible alpha handoff with actual limits and the user's immersion observations.

This item does not introduce another management application.
Use the console's existing instance, task, trace, and memory views.
Add inspection only where the new behavior needs it.

### Start from

A01 scenarios and holdout data, the historical evaluator, and all item handoffs.
Current console changes must remain intact.
Update documentation and tested dependency revisions after the final fixes.

Measure chat, decisions, background thought, embeddings, and body rendering together.
Inspect starvation and resource contention.
Tune frequency and selective work before increasing inference concurrency.

### Verify

Run the root contract suite and relevant cross-package compatibility checks.
Run all new live gates for the final revision.
Complete a two-hour mixed session for each selected persona.
Include idle activity, initiative, changed tasks, expected failures, disconnect, and restart.

Report rates with sample sizes and recorded conditions.
Keep unavailable gates separate from passing gates.
Verify zero unsupported completion receipts and no overlapping body mutations in acceptance scenarios.
Track intended deception separately from accidental unsupported public claims.
Use independent evaluation after generation.

### Manual test

Complete M7.
Record per-exchange regeneration wishes, continuity concerns, and memorable successful moments.
Choose the next focused iteration from observed failures.

### Handoff

Supply the alpha revision set, setup/run/recovery procedures, raw evidence locations, acceptance matrix, and remaining limitations.
Do not label the companion perfect because the engineering tests pass.
