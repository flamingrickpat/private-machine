# A01: Capture baseline and evaluation scenarios

## Summary

This item establishes a reproducible baseline and reviewed scenarios before implementation changes.
It is not implemented by this plan.

Parent: [ordered alpha plan](../index.md).
Dependencies: None.
Design: [verification](../verification.md) and [current-state audit](../current-state.md).

### Deliver

1. Capture the current working tree, dependency locks, configuration identities, and historical gate evidence without discarding uncommitted work.
2. Define conversation, classification, private-thought, reflection, and Minecraft scenarios with reviewed acceptance facts.
3. Provide repeatable local commands, isolated world fixtures, and a standard session handoff.

Record the four PM generations and supporting repository revisions.
Preserve the original brief and link its historical W0–W8 plan.
D09 confirms Spamuel/Jesse plus a contrasting cheerful persona.
D12 confirms Agentic Babymode plus isolated test worlds.
Do not turn a source review into a claim that an old runtime works.

### Start from

Current `tests/`, `tests/live/`, `config.example.yaml`, and `docs/workflows/`.
Inspect the existing conversation evaluator and Minecraft live harness before replacing anything.
Inspect the actual Babymode server configuration and fixture reset behavior.

### Verify

Repeat the root foundation suite and strict documentation build.
Record any change from the planning baseline of 257 passing tests.
Capture a short real conversation and the existing narrow Minecraft gate.
Label missing services as unavailable.

Create human-reviewed routing examples, including contradictory evidence and ambiguous reports.
Reserve a holdout set before tuning labels or thresholds.
The current LLM supplies comparison results, rather than truth labels.

### Manual test

Start the current console, complete a short exchange, inspect its memory and task evidence, and restart.
Record what the prototype actually does.

### Handoff

Supply exact commands, endpoint requirements, world reset instructions, baseline receipts, and the chosen initial matrix.
Do not begin later behavioral comparisons without this snapshot.
