# A08: Retrieve and learn from experienced memory

## Summary

This item makes relevant experiences retrievable and distinguishes them from background or imagined events.
It is not implemented by this plan.

Parent: [ordered alpha plan](../index.md).
Dependencies: A06, A07.
Design: [persistent state](../cognition.md#persistent-state-and-causes) and [second conscious loop](../private-loop.md#the-second-conscious-loop).

### Deliver

1. Integrate semantic and episodic retrieval into live cognition with scope, provenance, and snapshot constraints.
2. Consolidate meaningful dialogue, task progress, failures, and emotional consequences into retrievable experiences.
3. Maintain temporal activity summaries and conflict-aware belief updates without fabricating events.

D10 confirms capability and ontology consistency, with intentional deception distinct from unsupported generation.
Record the initial seed's provenance and interpretation explicitly.
Use existing reality/frame and provenance fields.
Distinguish background, actual experience, speculation, and predicted outcomes.

### Start from

`modules._memory_candidates`, `pm_core/ghost/service.py`, and `pm_core/embeddings.py`.
Preserve the user's current memory-search and console changes.
Inspect `runtime/consolidation.py` and existing spatial/body evidence models.

Live retrieval must respect the accepted frontier and allowed knoxel identifiers.
Avoid selecting unpublished future state during concurrent work.
Retrieve older relevant experiences beyond recent dialogue.

### Verify

Mention a preference, distract the companion, restart, then present a relevant situation.
Verify retrieval and behavior using the original evidence identifier.
Exercise corrected beliefs, stale world observations, imagined scenarios, and canon attribution.

Incremental task progress must become usable memory without repeatedly duplicating the same artifact.
A time-range query returns only activity executed within that interval.
Summaries retain evidence links for later inspection.
Retain a false utterance as an utterance with its prior deception intent, rather than promoting it to fact.
Reject unsupported generated sensory or emotional experiences from factual consolidation.

### Manual test

Ask about a past failed method and a remembered shared achievement.
Compare public recall with the original conversation or task journal.
Inspect why a competing memory was selected or rejected.

### Handoff

Supply retrieval rules, index preparation commands, consolidation semantics, temporal queries, and continuity evidence.
